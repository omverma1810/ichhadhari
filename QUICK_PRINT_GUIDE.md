# 🖨️ Quick Print Guide - TVS Electronics Shope 45

## ⚡ Fast Print Instructions

### 1️⃣ Open Invoice

```
Dashboard → Vendors → Invoices → Click any invoice
```

### 2️⃣ Click Print Button

```
Top right corner → Print button (or Ctrl/Cmd + P)
```

### 3️⃣ Printer Settings

```
✅ Printer: TVS Electronics Shope 45
✅ Paper Size: 80mm (or Custom: 80mm x Auto)
✅ Orientation: Portrait
✅ Margins: None
✅ Scale: 100%
```

### 4️⃣ Print!

---

## 📋 Checklist Before Printing

- [ ] Thermal paper roll is loaded
- [ ] Printer is connected and powered on
- [ ] Paper size set to 80mm
- [ ] No scaling/fit-to-page enabled
- [ ] Preview shows all content

## ⚠️ Common Issues & Quick Fixes

| Problem           | Solution                           |
| ----------------- | ---------------------------------- |
| Content cut off   | Set paper to exactly 80mm          |
| Text too small    | Don't zoom browser, use 100%       |
| Wrong alignment   | Clear browser cache (Ctrl+Shift+R) |
| Printer not found | Check USB/Bluetooth connection     |
